# Участие в Remains: Unity

Проектом единолично руководит и сопровождает его Hemito. Только он принимает
изменения в основную ветку, устанавливает roadmap и выпускает официальные релизы.
Помощь в разработке не передаёт права управления или права на оригинальные ресурсы.

## Ошибки и предложения

Используйте шаблоны Issues. Для бага укажите commit, Unity/Windows, шаги повторения,
ожидаемый и фактический результат, число игроков, host/client и сценарий сохранения.
Приложите очищенные от личных данных логи. Не публикуйте ключи, токены, IP других
людей, пользовательские сейвы и личные пути без необходимости.

Для предложения опишите проблему, ожидаемое поведение и совместимость с сетью,
сохранениями и модами. Наличие предложения не означает принятие его в roadmap.
Обнаруженный секрет не помещайте в публичный Issue: сообщите владельцу через
доступный приватный канал; автоматической службы security advisory пока нет.

## Pull Requests

До выбора лицензии кода условия лицензирования вкладов должны быть отдельно
согласованы с владельцем перед слиянием. PR не означает передачи исключительных
прав. Моды и неофициальные форки должны соблюдать права всех правообладателей и
не представляться официальными релизами проекта.

## Для владельца

Откройте вкладку Pull requests, изучите Files changed и происхождение ресурсов,
проверьте изменения в отдельной ветке. При необходимости выберите Request changes.
Для принятия используйте Merge pull request; для отклонения — Close pull request
с кратким объяснением. Правила управления не требуют выдачи collaborator доступа.
Не используйте force push. Перед запуском чужих скриптов и workflow изучите их.
