# Штатный 2D-риг пони

Откройте NativePony.unity. Слева PonyAnimation с Animator, справа PonyPosing с родным IK Manager 2D. Это отдельный образец; игровая кукла не заменена.

## Анимация

Выберите корень PonyAnimation, откройте Window → Animation → Animation. Выберите Idle, Walk или LegCurl. Ключи — обычные Transform; их можно редактировать штатными средствами. Перед изменениями сохраните копии клипа и префаба.

## Постановка позы

В PonyPosing выберите Controls → frontNearTarget и перемещайте его инструментом Move в плоскости XY. Остальные копыта имеют свои цели. Родной Limb Solver управляет двумя нижними звеньями; плечо/бедро можно вращать отдельно. У Solver есть Flip для выбора стороны сгиба.

## Внешность

На корне компонент Sprite Library. Поменяйте Sprite Library Asset на Bare, Antirad, Creator или AntiradCreator. Все варианты используют одинаковый скелет.

## Сетка и веса

Выберите PNG в Art, нажмите Sprite Editor → Skinning Editor. Сетка, кости и веса сохранены в импортере PNG. В этом образце здесь редактируются сетка и веса. Изменение исходных костей в одном PNG не обновляет общий скелет и остальные слои: для смены bind-позы требуется согласованное обновление всех спрайтов и префаба. Четыре ноги — сплошные деформируемые спрайты, голова и туловище жёсткие. Исходные рисунки пока сохранены, художественная очистка контуров и сгибов не выполнена.

## Границы

Цвета запечены для образца. Независимая мимика, произвольное смешивание одежды, игровое освещение, силуэты теней и подключение к боевым состояниям не переносились. По сравнению с исходным составом рисунка изменён порядок девяти крупных слоёв. Образец использует штатный Sprite-Unlit материал и SpriteSkin с включёнными CPU-данными для диагностики; производительность полного завода не заявляется.
