# Remains: Unity

Экспериментальный независимый фанатский remake игры **Remains** автора **Empalu**
на Unity с сетевым кооперативом. Это не официальный продукт Empalu или оригинальной
команды. Авторство оригинальной графики, звуков и контента не принадлежит
сопровождающему этого проекта.

Игра находится в разработке: это незавершённый эксперимент, а не полный перенос
оригинала и не стабильный релиз. Multiplayer работает на Mirror/KCP; отдельные
кооперативные сценарии проверены двумя процессами на одном ПК. LAN на двух
физических ПК и четыре игрока пока не объявляются проверенными.
