# Моды локализации

Это данные для Unity Localization, отдельно от игровых модов. Переводы не меняют игровой fingerprint и не требуют одинакового набора переводов у игроков.

Скопируйте `load-order.json` и папку `example-ui` в `Remains_Data/StreamingAssets/LocalizationMods/` рядом с установленной игрой. В Editor корень — `RemainsUnity/Assets/StreamingAssets/LocalizationMods/`. Пример изначально выключен: для включения поменяйте `enabled` на `true`, затем перезапустите игру. Отсутствующий список означает отсутствие модов переводов; включённый повреждённый пакет вызывает явную ошибку, а не частичное применение.

`load-order.json` имеет `schema: 1` и упорядоченный массив `mods`. У каждой записи обязательны уникальный `id`, относительная папка `path` внутри этого корня и явно заданный `enabled`. В папке лежит `manifest.json`. Абсолютные пути, выход за корень и повтор одной папки запрещены. Выключенный пакет не читается, но его запись списка всё равно должна быть корректной.

В манифесте обязательны `schema: 1`, стабильный `id`, `version` и массив `strings`. `id` совпадает со списком. `dependencies` перечисляет ID уже включённых пакетов, стоящих раньше. Это порядок загрузки, без автоматического поиска и включения зависимостей.

Запись перевода содержит `table`, стабильный `key`, `locale`, непустой `value`, `replace` и `replaces`. Встроенные таблицы: `Remains.UI`, `Remains.Items`, `Remains.Original`. Новые таблицы называются с префиксом своего ID и точкой: `example:ui.Messages`. Перевод таблицы другого мода разрешён, если его ID указан в зависимостях.

Чтобы заменить существующий перевод, нужны `replace: true` и точный текущий источник в `replaces`: `base` для игры либо ID предыдущего мода. Для новой записи — `replace: false`, `replaces: null`. Неявная перезапись, неправильный источник замены и повтор одной пары таблица/ключ/язык внутри пакета отклоняются. Новый ключ обязан иметь русский исходник; переводы на другие языки добавляются к нему.

Базовые коды: `ru`, `en`, `uk`, `zh-Hans`, `zh-Hant`, `pl`, `de`, `es`, `ja`. Исторические `ua`, `jp`, `zh`, `tw` в модах не принимаются. Новый язык объявляется через `locales: [{"code":"fr","nativeName":"Français"}]`; его можно использовать в этом и последующих пакетах. Пустая таблица нового языка допускает обычный переход к русскому исходнику; отсутствующие переводы диагностирует игровой сервис локализации.

Пример меняет английский `unity/language`, объявляет французский язык и добавляет собственный ключ с русским и французским текстом. Собственный ключ сам по себе не создаёт UI: интерфейс мода должен запросить его по таблице и ключу.

Загрузка выполняется один раз при запуске. Сначала проверяется весь план, затем копии встроенных Unity-таблиц; исходные Addressables-ассеты не изменяются. Поставщик и его копии живут до освобождения базы локализации; его нельзя освобождать, пока UI использует таблицы. Горячая перезагрузка этим форматом не предусмотрена. Ошибки содержат ответственный ID, позицию списка и ключ или путь; исправьте пакет и запустите игру заново.
