# Проверка собственных переводов

`Validate.csproj` — самостоятельная C#-проверка без NuGet-зависимостей:

```powershell
dotnet restore Tools/LocalizationOwn/Validate.csproj --ignore-failed-sources -p:NuGetAudit=false
dotnet run --no-restore --project Tools/LocalizationOwn/Validate.csproj -- .
```

Проверяются уникальные table/key между авторскими пакетами, непустые переводы, коды языков, индексы и форматы аргументов, отсутствие случайно оставленной кириллицы вне украинского. Полноту конечных таблиц проверяет Unity-импортёр: авторские пакеты не обязаны дублировать уже существующие переводы.

`item-glossary.json` содержит 42 различных русских текста предметов и восемь авторских переводов каждого. Развёрнутый пакет `Editor/LocalizationOwnItems.json` содержит записи по стабильным ключам. Пересоздание из глоссария выполняет тот же C#-инструмент с аргументом `--generate-items`. После него автоматически выполняется валидация. Для предметов сначала редактируйте глоссарий, затем пересоздавайте пакет; соответствие русского источника проверяет основной импортёр. Два пакета UI редактируются непосредственно по table/key. Полный импорт и проверка фактического покрытия: `Remains.Editor.UnityLocalizationChecks.RunBatch` в закрытом Unity Editor.
